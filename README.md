# RandlesID

An R package for fast computation of Randles interdirections for multivariate data in dimension $d \geq 3$.

## Installation

You can install the development version directly from GitHub:

```r
# install.packages("remotes")
remotes::install_github("ErikMendros/RandlesID")
```

## Usage

The main function is `randles_interdirections()`.

Given an $n \times d$ data matrix, it computes the complete $n \times n$ matrix of Randles interdirection counts.

### Example

```r
library(RandlesID)

set.seed(123)

n <- 20
d <- 4

X <- matrix(
  rnorm(n * d),
  ncol = d
)

ID <- randles_interdirections(X)

ID
```

The entry `ID[i, j]` is the number of hyperplanes through the origin determined by $d-1$ observations other than $X_i$ and $X_j$ that separate $X_i$ and $X_j$.

## Algorithm

In dimension three, the algorithm uses a gnomonic projection followed by a sweep of the resulting planar line arrangement.

For dimensions $d > 3$, the problem is reduced to a collection of three-dimensional problems by quotienting out spans generated by $d-3$ observations.

For fixed dimension $d$, the current implementation has time complexity

$$
O(n^{d-1}\log n).
$$

The (unnecessary) logarithmic factor comes from sorting the line-arrangement crossings in the three-dimensional base algorithm.

The implementation assumes that the observations are in general position.
